# whisperqueue-site

Documentation and website for WhisperQueue — built with Astro.

## Stack

| Concern | Tool |
|---|---|
| Framework | Astro |
| Styling | Tailwind CSS |
| Theme | Dark mode only (see DESIGN.md) |
| Search | Pagefind |
| Deployment | GitHub Pages via GitHub Actions |
| Domain | whisperqueue.axmdev.app |
| Runtime | Bun |

## Scope

- **Landing page** — marketing/hero page following the DESIGN.md hero pattern
- **Docs** — server API documentation (SDK docs added later as SDKs are built, no placeholders)
- Static only — no API playground or interactive elements

## Docs source

All documentation markdown lives in this repo. Not pulled from other repos.

## Design

Follow the WhisperQueue design system defined in `project-docs/DESIGN.md`. Dark-only, warm tones, no light mode.
